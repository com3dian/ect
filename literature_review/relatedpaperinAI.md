[Going Beyond Neural Network Feature Similarity: The Network Feature Complexity and Its Interpretation Using Category Theory](https://arxiv.org/abs/2310.06756)

> Category Theory in Machine Learning Category theory have been used in machine learning (Shiebler et al., 2021) for various topics including backpropagation (Fong et al., 2019), categorical probabilities (Fritz, 2020), conditional independence (Mahadevan, 2022a), supervised learning (Harris, 2019), reinforcement learning (Mahadevan, 2022b) and so on. Among them, Bradley et al. (2022) provides an enriched category theory of natural language while Yuan (2023) provides an analysis upon the power of perfect foundation models from category theory perspective. These previous works define different categories and functors from different perspective. In this paper, we provide a new perspective by defining the category regarding the network structure and the functor corresponding to the parameterization of the network.

## Daphne Wang

[Extracting structure from an LLM - how to improve on surprisal-based models of human language processing](https://aclanthology.org/2025.coling-main.329/)

This paper argues that word surprisal alone cannot fully explain how humans process difficult sentences. In particular, it struggles with “garden-path” sentences, where readers initially choose the wrong interpretation and must later revise it. The authors combine an LLM’s word predictions with grammatical structure to measure both how unexpected a word is and how much it conflicts with the reader’s current interpretation. This approach predicts human reading times better than surprisal alone.
